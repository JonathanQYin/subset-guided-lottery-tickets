Reading select_subset.py

Follow one selection run from a dense reference checkpoint to a fixed list of training image IDs. Read the method you plan to use, or compare how all eight methods pick their members.

Example command

$subset = .\.venv\Scripts\python.exe select_subset.py --arch resnet32 --seed 0 --method feature_cluster --subset-fraction 0.25 --reference-epoch 10 | Select-Object -Last 1

This PowerShell example runs one selection method from the project folder and captures its output path in $subset. To study difficult examples by loss, use --method loss --difficulty hard with the same fraction and reference epoch.

From main() go to select(). Follow random sampling, difficulty scoring, or clustering, then look at the JSON handoff.
